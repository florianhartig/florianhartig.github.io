We develop our research software in the open. Code and data are public goods
of science: publishing them makes our results transparent and reproducible,
and lets others build on them rather than start from scratch.

Below are the R packages we develop or contribute to. Code and data that
accompany individual papers are on the
[group software page](https://www.uni-regensburg.de/biologie-vorklinische-medizin/forschen/arbeitsgruppen/ag-hartig/software),
in the [Theoretical Ecology GitHub organisation](https://github.com/TheoreticalEcology),
on [my GitHub account](https://github.com/florianhartig), and on the pages of
individual group members.
