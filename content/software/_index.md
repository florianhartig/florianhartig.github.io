Our lab is committed to free and open provision of scientific source code and
data, both to make our research transparent and reproducible, and because we
believe that scientific code and data are essentially public goods to which all
researchers should contribute.

The packages below are the ones we develop or contribute to directly. For the
fuller picture, including code and data accompanying individual papers, see the
[group software page](https://www.uni-regensburg.de/biologie-vorklinische-medizin/forschen/arbeitsgruppen/ag-hartig/software),
the [Theoretical Ecology GitHub organisation](https://github.com/TheoreticalEcology),
and [my own GitHub account](https://github.com/florianhartig) — as well as the
sites and GitHub accounts of individual group members.
